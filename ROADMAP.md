# Roadmap

## Near Term

- Expose ontology entities directly in the API.
- Add UI panels for decisions, approvals, recommendations, mitigations, and observations.
- Add extraction trace UI for confidence and rationale review.
- Introduce Alembic migrations.
- Externalize frontend API base URL.

## Medium Term

- Human validation workflow and adjudication dashboard.
- Real-world PMO corpus validation.
- Managed database deployment profile.
- Authentication and role-based access control.
- Exportable governance report packs.

## Long Term

- Enterprise connectors for SharePoint, Teams, Jira, ServiceNow, and Confluence.
- LLM-assisted executive narrative generation with citation grounding.
- Portfolio-level risk trend analytics.
- Continuous monitoring jobs for recurring governance packs.
