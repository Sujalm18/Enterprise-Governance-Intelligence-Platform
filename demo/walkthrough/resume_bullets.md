# Resume Bullets

- Built an enterprise governance intelligence platform using FastAPI, Streamlit, SQLAlchemy, and Python to process PDF, DOCX, TXT, and XLSX governance artifacts.
- Designed an ontology-aware extraction layer that separates risks, issues, dependencies, decisions, approvals, recommendations, escalations, and action items.
- Implemented OCR-ready PDF ingestion with text-quality heuristics and EasyOCR fallback for scanned or malformed PDFs.
- Created a precision-first semantic filtering pipeline to suppress false positives from generic policies, meeting discussion, and governance commentary.
- Developed a 90-document mixed-format regression testing framework with classification, governance precision, RAID recall, escalation false-positive, and meeting-action metrics.
- Added deployment-ready Docker artifacts, environment configuration, health checks, and professional architecture documentation.
